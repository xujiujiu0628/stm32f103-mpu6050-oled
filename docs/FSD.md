# FSD: stm32f103-mpu6050-oled 功能规格

## 1. 概述

STM32F103C8T6（Blue Pill）通过软件 I2C 读取 MPU6050 6 轴数据，融合成欧拉角，在 SSD1306 OLED 上以 4 种状态显示（3 个内容页 + 1 个关屏页），PA0 按键切换。

## 2. 目标

- 验证 D:\claude 嵌入式工作台在多模块 + 多外设 + 状态机项目上的端到端能力
- 实现 MPU6050 → OLED 数据流
- 实现按键驱动的页面切换

## 3. 功能需求（FR-XXX-NN）

### FR-BOOT-01：启动横幅
- **描述**：上电输出启动横幅（版本可追溯）
- **接受准则**：RTT 捕获到 `[BOOT] stm32f103-mpu6050-oled v0.1`
- **来源**：既有实现回填（2026-09-11 F-113 对账，expectations FR-BOOT-01 的出处补录——代码里发现的行为≠需求，经裁决升格为 approved）

### FR-MPU-01：MPU6050 地址探测
- **描述**：启动时探测 MPU6050 I2C 地址
- **接受准则**：先 0x68 探测，失败回退 0x69；WHO_AM_I 寄存器返回值必须等于 0x68
- **失败处理**：探测失败显示 "MPU6050 FAIL"

### FR-MPU-02：MPU6050 6 轴原始数据采集
- **描述**：100Hz 频率采集加速度 ax/ay/az + 陀螺仪 gx/gy/gz
- **接受准则**：1s 内至少 90 次新数据（RTT 计数自检）
- **量程**：加速度 ±2g，陀螺仪 ±250°/s

### FR-MPU-03：欧拉角融合
- **描述**：互补滤波融合加速度+陀螺仪算 Roll/Pitch，Yaw 纯陀螺仪积分
- **接受准则**：静止时 Roll/Pitch 标准差 < 1°（10s 采样验证）
- **公式**：α=0.98 陀螺仪权重

### FR-OLED-01：OLED 启动画面
- **描述**：启动时显示 MPU6050 探测结果
- **接受准则**：启动 1s 内显示 "MPU6050 OK @ 0x68" 或 "@ 0x69"
- **失败显示**："MPU6050 FAIL" + "Check HW"

### FR-DISP-02：OLED 10Hz 显示刷新
- **描述**：10Hz 频率刷新 OLED 屏幕
- **接受准则**：1s 内 8-12 次刷新（10Hz ±20%）
- **节流**：100ms 间隔
- **来源**：本条原占用 FR-OLED-02 编号，2026-09-11 F-113 对账时发现与 expectations
  FR-OLED-02（关屏节流）同 ID 异义，按"新增编号不回收"纪律迁出；原 FR-OLED-02
  编号让位给 expectations 现义（见下条 superseded 注记）

### FR-OLED-02：关屏节流（数据侧）
- **描述**：进入关屏状态（STATE=3）后 RTT 周期性数据行不再出现
- **接受准则**：关屏后采集窗内无 `[STATE=3 last=` 之外的周期数据行增长
- **superseded 注记**：本编号原义"10Hz 显示刷新"已迁至 FR-DISP-02；此处与
  expectations.json FR-OLED-02 现义对齐（F-113 漂移处置，v0.5 发布时该断言
  即以节流为判据）

### FR-OLED-03：OLED 4 状态显示
- **描述**：4 个显示状态（3 内容 + 1 关屏）
- **状态 0**：六轴原始数据（ax/ay/az + gx/gy/gz，2 列 3 行）
- **状态 1**：欧拉角（Roll/Pitch 数值，Yaw: live 文字占位）
- **状态 2**：2D 姿态点图（中心十字 + 参考圆 + 实时点，±90° 满量程）
- **状态 3**：关屏（SSD1306 命令 0xAE）

### FR-KEY-01：按键消抖
- **描述**：PA0 按键 50ms 消抖
- **接受准则**：抖动信号不触发事件

### FR-KEY-02：长短按识别
- **描述**：按下持续 < 1000ms 为短按，≥ 1000ms 为长按
- **接受准则**：短按触发 KEY_EVENT_SHORT，长按触发 KEY_EVENT_LONG（一次性）

### FR-KEY-03：状态机切换
- **描述**：按键事件驱动状态机
- **短按**：0→1→2→0 循环
- **长按**：任意非关屏状态 → 关屏
- **关屏短按**：唤醒到关屏前状态
- **关屏长按**：无操作

### FR-PWR-01：关屏实现
- **描述**：关屏用 SSD1306 命令 0xAE（display off），不切 VCC
- **接受准则**：关屏后屏幕黑屏，后台任务（采样+滤波）继续运行

### FR-PWR-02：唤醒保留状态
- **描述**：关屏前显示的页面被记住，唤醒后回到该页面
- **接受准则**：状态 1 长按关屏 → 短按唤醒 → 状态 1（不是 0）

## 4. 非功能需求

### NFR-01：性能
- 主循环 tick 频率：1ms（SysTick）
- MPU6050 采样：100Hz
- OLED 刷新：10Hz
- 按键响应延迟：< 20ms
- 采样→显示端到端延迟：< 100ms

### NFR-02：内存
- flash < 50KB（实测 16KB）
- SRAM < 20KB（实测 bss 3.3KB）

### NFR-03：构建
- GCC 0e0w（零错误零警告）
- 工具链：arm-none-eabi-gcc 10.2021.10 + MSYS2 make
- 烧录：OpenOCD + ST-Link

### NFR-04：可维护性
- 代码按模块分子目录（User/mpu6050/、User/oled_view/、User/key/）
- 复用 adc-oled 已有 MyI2C.c / My_OLED.c / Drivers/ / ThirdParty/RTT/
- 关键决策有 ADR 文档

## 6. 硬件扩展需求（v0.6，2026-09-12）

**硬件变更**：电位器三脚接入面包板——中间抽头→**PA6**，两端→3V3/GND；
新增按键 **KEY1 = PB15→GND**（内部上拉，按下=低，与 PA0 极性相反勿混）。
PA0 / PB8-9 / PB10-11 不变。

### FR-BOOT-02：启动横幅含重校准提示
- **描述**：上电 RTT 输出固定提示行，告知用户 PB15 长按 = 陀螺仪重校准
- **接受准则**：RTT 捕获含 `[BOOT] PB15 long = recalibrate gyro`
- **禁止发生**：提示行出现在硬件初始化失败告警之前（说明它被放在 init 前打印=误导）
- **Tier**：bench（verify 断言 FR-BOOT-02）

### FR-BRT-01：亮度评估引擎心跳
- **描述**：ADC1_IN6 每 50ms 评估拍对 PA6 做 8 点滑窗平均并过滞回判档；
  `[BRT] band=... mv=...` 行以 1Hz 心跳输出（锚可靠性不赌上电首拍——RTT
  512B 环形缓冲下一次性首拍行有被 banner/STATE 先头连覆盖的风险；1Hz 稳锚
  且 mv 全程可观测）
- **接受准则**：90s 采集窗内 RTT 出现 `[BRT] band=`（ADC init 失败则改发
  `[BRT] adc init FAIL` 且本条判 FAIL——断言兼作 ADC 哨兵）
- **禁止发生**：每评估拍（50ms）都刷 `[BRT]` 行（淹没采集窗）；档位未变
  仍下发对比度 I2C 命令（心跳与命令下发解耦，后者仅变档/唤醒时）
- **Tier**：bench（verify 断言 FR-BRT-01）

### FR-BRT-02：三档滞回阈值正确
- **描述**：LOW/MID/HIGH 进入边界 1150 / (1000↔2650 滞回带) / 2800 mV，
  对应对比度 0x40 / 0x8E / 0xFF；边界 ±150mV 内噪声零翻转
- **接受准则**：host 单测 21 例全绿（含抖振序列哨兵）+ 拧电位器实测三档
  均出现、临界位置不来回跳档
- **Tier**：host（算法本体，tests/test_brt_band.c）；bench 端到端需人工
  拧电位器 → 机器断言豁免（见 expectations.waived）

### FR-BRT-03：档位变化即时生效且不刷屏占用
- **描述**：仅档位变化时发 0x81+值 两条软 I2C 命令（~0.3ms）；关屏期间
  挂起不下发，唤醒后强制补发当前档
- **接受准则**：变档 ≤100ms 屏亮度可察觉变化；正常窗内无 `[BRT]` 重复行
- **Tier**：bench 人工观察 → waived

### FR-CAL-01：PB15 长按触发陀螺仪重校准
- **描述**：按住 PB15 ≥1000ms（低有效）→ 立即整帧刷校准覆盖层 → 静止
  采样 1s 重算偏置；PB15 短按忽略；上电一次自动校准保持不变
- **接受准则**：RTT 出现 `[CAL] done gx=…`，且校准后静止时 gx/gy/gz≈0、
  roll/pitch 漂移率与上电校准同量级
- **禁止发生**：校准采样期间穿插整帧刷屏（软 I2C 13ms 阻塞污染采样 dt——
  覆盖层必须刷完再采样）；偏置未清零重算的假校准（旧 bias 残留=没校）
- **Tier**：bench（verify 断言 FR-CAL-01 已翻正——2026-09-12 用户自持窗
  XPASS 捕获 `[CAL] done` 后按落地信号翻转）

### FR-CAL-02：校准覆盖层提示
- **描述**：校准期间全屏 `CALIBRATING... / Keep still`；结束自动恢复当前页
- **接受准则**：人工目测覆盖层出现与撤销各 ≤1 显示拍
- **Tier**：bench 人工观察 → waived
